# 👋 关于我

欢迎来到我的博客！我是 **一名来自江西的前端程序员**，正在向全栈开发的道路迈进。这里记录了我的技术成长，希望与你一同见证每一步进步。

## 🌟 我的兴趣

- **✈️ 旅游**：旅行让我看到更广阔的世界，也找到更多灵感。
- **🌊 看海**：面对浩瀚的海洋，总能让我思考人生。
- **🎮 游戏**：热爱在 **英雄联盟** 的战场中秀操作，也喜欢在《**我的世界**》里建造梦想国度。

- **后端开发**：NestJS、MySQL、Docker 和 Nginx。

## 🎯 我的目标

我的职业目标是成为一名全栈型技术人才，不仅熟练掌握前后端开发，还能独立完成从需求到部署的完整项目实现。  
未来，我希望能通过编程实现经济自由，并拥有更多的时间去探索世界、享受生活。同时，我也希望用技术创造价值，解决实际问题，让代码成为改变世界的小力量。
